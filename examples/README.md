# Scan fixtures

`vulnerable/` contains intentionally insecure Python, Java, and C source samples for demonstrating the scanner. They are input fixtures, not a runnable application or a collection of recommended cryptographic implementations. Scanning them does not require installing their imported cryptographic libraries or compiling them.

Use the dashboard's directory upload to work on copied fixtures. A CLI scan records the original paths, so make a separate copy before applying edits to a CLI-created case.
